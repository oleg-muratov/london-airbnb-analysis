Download the dataset from https://www.kaggle.com/datasets/labdmitriy/airbnb
and place the CSV files in this directory.

Expected files:
- calendar.csv
- listings.csv
- listings_summary.csv
- reviews.csv
- reviews_summary.csv
- neighbourhoods.csv

If you replace the CSVs, delete `data/interim/` first: the calendar cache is rebuilt from them
only when it is missing.
